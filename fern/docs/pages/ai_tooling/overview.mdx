Schematic hosts an MCP server at `https://api.schematichq.com/mcp`. Any MCP-compatible assistant can connect to it and work against your real account: the companies you have, the plans they are on, the features they are entitled to, and the usage they have recorded.

Two audiences use the same server for different work, and the docs split along that line.

## What you decide at sign-in

Both paths run the same OAuth flow, and that flow asks you two questions worth answering deliberately.

**Which environment.** Each Schematic environment carries its own companies, plans, and features. A connection to sandbox looks like an empty account next to your production data, and the assistant reports it as an empty account rather than as a wrong environment. Pick the one you mean.

**Read-only, or read and write.** Read-only is the right default for anything you are only asking questions about. Choose read and write when you intend the assistant to change an entitlement or create a feature. A write connection can never do more than you can do in the Schematic app yourself.

Both choices are fixed for the life of the connection. To change either one, disconnect the server in your client and connect again.
