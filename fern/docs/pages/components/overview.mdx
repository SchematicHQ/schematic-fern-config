Schematic gives you two ways to put billing UI in your app. Both read one data layer, so you can mix them: a custom portal with a drop-in checkout is a normal setup.

## Which path?

| | Drop-in components | Build your own UI |
| --- | --- | --- |
| You want | Billing UI working today, in Schematic's layout, with your colors and fonts. | Your own layout in your own design system, or an agent writing it for you. |
| You write | A provider, a session, and one tag per card. | A hook call, a derivation, and the JSX. Reference code gets you most of the way. |
| Styling | `--schematic-*` tokens, `color-scheme`, or your own CSS on stable class names. | Anything. The derivations return structured parts, not sentences. |
| Checkout | `<Checkout/>`, opened by Plan Manager, Pricing Table, Credit Meter, and Feature Meter. | `useCheckout` on the checkout API. Take payment with Stripe Elements if you like. |
| Frameworks | React. | React hooks. The client and derivations are plain TypeScript for Vue and Angular. |

## One setup for both

Every component and every hook reads from one provider. Your server mints a short-lived access token for the signed-in company, and the browser never sees your secret key.

```tsx
import { SchematicProvider } from "@schematichq/schematic-react";

<SchematicProvider
  publishableKey="pk_…"
  // Whose billing is being read: signed in, null for signed out, undefined while auth resolves.
  session={{ company: company.id, user: user.id, token: fetchAccessToken }}
>
  {children}
</SchematicProvider>
```

The [Quickstart](/components/quickstart) walks through the token exchange and the first component.

## What's in the box

| Component | Hook | Reads |
| --- | --- | --- |
| `<Invoices/>` | `useInvoices` | Invoice history, paged |
| `<UpcomingBill/>` | `useUpcomingInvoice` | Next bill, balance, discounts |
| `<PaymentMethods/>` | `usePaymentMethods` | Cards and wallets on file |
| `<IncludedFeatures/>` | `useFeatureUsage` | Entitlements and usage |
| `<PlanManager/>` | `useCompany` | Plan, add-ons, notices, change plan |
| `<CreditMeter/>` | `useCreditBalances` | Balances and grants per credit, buy more |
| `<FeatureMeter/>` | `useFeatureUsage` | Meters for metered features |
| `<PricingTable/>` | `useCatalog` | Plans and add-ons, public or company |
| `<Checkout/>` | `useCheckout` | The persisted checkout |
| `<Unsubscribe/>` | `useUnsubscribe` | Cancel with your rules applied |
