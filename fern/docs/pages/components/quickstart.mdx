Four steps take you from an empty page to a live billing portal for the signed-in company. The same setup serves every drop-in component and every hook.

### 1. Install the packages

```sh
npm install @schematichq/schematic-react @schematichq/schematic-components @stripe/stripe-js @stripe/react-stripe-js
```

The React package carries the provider and the hooks. The components package carries the drop-ins and the derivations the reference code uses. The two Stripe packages are peers of the components; Checkout and Payment Methods load them when a payment form opens.

### 2. Mint access tokens on your server

Components read a company's own billing state, so they authenticate with a short-lived, company-scoped temporary access token. Your server issues it with your secret key; the browser only ever sees the token. Put the endpoint behind your own auth and resolve the company from the signed-in session, never from the request.

<Tabs>
  <Tab title="Node.js">
```typescript
// GET /api/accessToken
import { SchematicClient } from "@schematichq/schematic-typescript-node";

const client = new SchematicClient({ apiKey: process.env.SCHEMATIC_SECRET_KEY });

export async function GET() {
  const session = await getSession(); // your own auth
  if (!session?.companyId) return new Response("Unauthorized", { status: 401 });

  const response = await client.accesstokens.issueTemporaryAccessToken({
    lookup: { id: session.companyId }, // a company key configured in Schematic
  });
  return Response.json({
    token: response.data.token,
    expiresAt: response.data.expiredAt,
  });
}
```
  </Tab>
  <Tab title="Python">
```python
import os

from schematic import Schematic

client = Schematic(os.environ["SCHEMATIC_SECRET_KEY"])

def access_token(company_id: str) -> dict:
    response = client.accesstokens.issue_temporary_access_token(
        lookup={"id": company_id},
    )
    return {
        "token": response.data.token,
        "expiresAt": response.data.expired_at.isoformat(),
    }
```

### 3. Wrap your app in the provider

```tsx
// app/providers.tsx
"use client";
import { SchematicProvider } from "@schematichq/schematic-react";

async function fetchAccessToken() {
  const response = await fetch("/api/accessToken");
  return response.json(); // { token, expiresAt }
}

export function Providers({ children, company, user }) {
  return (
    <SchematicProvider
      publishableKey={process.env.NEXT_PUBLIC_SCHEMATIC_PUBLISHABLE_KEY}
      session={{ company: company.id, user: user.id, token: fetchAccessToken }}
    >
      {children}
    </SchematicProvider>
  );
}
```

`session` says whose billing is being read. Pass `null` when nobody is signed in and `undefined` while your auth is still resolving; [Session and access tokens](/components/build-your-own/session) explains why the three differ. Leave `user` out when your tokens are company-wide.

### 4. Render the portal, or a hook

<Tabs>
  <Tab title="Drop-in">
```tsx
import {
  CheckoutLauncherProvider, CreditUsage, IncludedFeatures, Invoices, MeteredFeatures,
  PaymentMethods, PlanManager, SchematicStyles, UnsubscribeButton, UpcomingBill,
  useCheckoutLauncher,
} from "@schematichq/schematic-components/elements";

export default function BillingPage() {
  return (
    <CheckoutLauncherProvider>
      <SchematicStyles />
      <Portal />
    </CheckoutLauncherProvider>
  );
}

function Portal() {
  const { open } = useCheckoutLauncher();
  return (
    <>
      <PlanManager onChangePlan={() => open()} />
      <IncludedFeatures />
      <MeteredFeatures onAddMore={() => open({ steps: { initial: "usage" } })} />
      <CreditUsage onBuyMore={() => open({ steps: { initial: "credits" } })} />
      <UpcomingBill />
      <PaymentMethods />
      <Invoices />
      <UnsubscribeButton onManagePlan={() => open()} />
    </>
  );
}
```

Render `<SchematicStyles />` once and drop any card you do not need; each stands alone. `CheckoutLauncherProvider` renders one `<Checkout />` for the page and `useCheckoutLauncher().open()` opens it. Plan Manager, Metered Features, Credit Usage, and Unsubscribe Button show Change plan, Add more, Buy more, and Manage plan only when you pass a handler or URL, so `Portal` hands each of them `open`.
  </Tab>
  <Tab title="Build your own">
```tsx
import { useInvoices } from "@schematichq/schematic-react";
import { deriveInvoiceList } from "@schematichq/schematic-components/elements";

export function InvoiceHistory() {
  const { data, loadMore } = useInvoices();
  if (data === undefined) return null;

  const list = deriveInvoiceList(data, { locale: "en-US" });
  return (
    <ul>
      {list.rows.map((row) => (
        <li key={row.id}>
          <a href={row.url ?? undefined}>{row.dateText}</a> {row.amountText}
        </li>
      ))}
      {list.hasMore && <button onClick={loadMore}>Load more</button>}
    </ul>
  );
}
```
